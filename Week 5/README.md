# Week 5 – The Data Audit

## Project Title

The Heat Is On: A Visual Timeline of Global Warming

## Course

24ADI204 – Data Science and Visualization

## 1. Introduction

This week focuses on auditing the Earth Surface Temperature dataset used in our global warming project. The audit examines the structure, completeness, consistency, and statistical characteristics of the data before further analysis.

## 2. Objectives

* Understand the structure of the temperature dataset.
* Identify missing values and duplicate records.
* Examine data types and numerical attributes.
* Calculate descriptive statistics.
* Visualize historical temperature patterns.
* Prepare a validated dataset for Week 6 feature engineering.

## 3. Dataset Description

The project uses historical Earth Surface Temperature data to study changes in temperature over time. The dataset contains date information and temperature-related attributes. The exact number of records, columns, and date range will be reported from the dataset used in the analysis.

## 4. Methodology

1. Load the existing project dataset.
2. Inspect rows, columns, data types, and summary information.
3. Calculate missing-value counts and percentages.
4. Identify duplicate records.
5. Calculate descriptive statistics.
6. Visualize missing values and temperature trends.
7. Clean and validate the data where necessary.
8. Save the processed dataset and analysis outputs.

## 5. Visualizations

* Missing-value analysis
* Historical temperature trend
* Temperature distribution

## 6. Expected Outcome

The audit provides information about data quality and historical temperature patterns. The validated dataset and findings will be used in Week 6 for feature engineering.

## 7. Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn, and Jupyter Notebook.

## 8. Conclusion

The data audit helps identify data-quality issues and summarize the characteristics of the historical temperature dataset. The analysis provides a foundation for reliable preprocessing and visualization in the next stage of the project.
